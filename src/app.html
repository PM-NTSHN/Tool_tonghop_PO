Công cụ tổng hợp PO / Yêu cầu đặt hàng theo Hãng

Nạp file Excel raw xuất từ Base Service → tự động chuẩn hóa sang template Data_sạch → phân tích, lọc, cảnh báo và xuất báo cáo Excel.

Kéo-thả file Excel vào đây

hoặc bấm để chọn file · hỗ trợ .xlsx / .xls (raw Base Service hoặc file Data_sạch đã chuẩn hóa)

1
Nạp file rawService Tickets – Yêu cầu đặt hàng (export từ Base).
2
Tự động convertChuẩn hóa KH, Hãng, Đại lý, Sale, ngày tháng, cờ review – đúng logic convert_service_tickets.py.
3
Phân tích & lọcLọc đa tiêu chí, biểu đồ động, cờ nhắc cập nhật, tuân thủ HĐ – BB thanh lý.
4
Xuất kết quảTải file Data_sạch và báo cáo “Tổng hợp PO_Hãng_Tháng M.YYYY.xlsx”.
Xử lý 100% trên trình duyệt của bạn, không cần internet, không gửi dữ liệu đi đâu.
